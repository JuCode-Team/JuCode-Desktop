- 移除 Agent 和派发功能，改为简单的定时任务。定时任务可设置名称、提示词、项目目录、引擎（JuCode、Claude Code、Codex）、权限模式和重复规则，每次运行开一个普通会话。只在运行失败、等待审批或被跳过时提醒。
- 升级后首次启动时，原 Agent 的定时任务自动转为新的定时任务，Agent 的会话转为普通会话并归档，其余数据移到 `~/.jucode/backup-agents-<时间>/`，不删除任何内容。
- 子智能体、工作流和后台命令集中显示在对话右侧的「后台任务」区域，可查看计划、进度和输出，也可停止。原智能体追踪标签、进度托盘和子智能体标签页已移除。
- 手机端只显示定时任务列表，可开关和立即运行。
- 修复应用运行一段时间后，新建对话显示「该对话已关闭」的问题。
- 写入大文件时，卡片实时显示文件名和增删行数。
- 账号卡片立即显示上次获取的数据，并在后台刷新。
- 修复右下角通知框抽动的问题，通知弹出和消失都有动画。
- 从定时任务打开 Claude Code 或 Codex 的运行记录时，按原引擎打开。
