- 支持接入第三方编码工具：OpenCode、oh-my-pi 和 Pi 通过标准 ACP 运行，可以在新对话的引擎菜单里直接选择。支持流式回复、审批、取消、切换模型和模式、上下文用量，关闭后重新打开会恢复对话历史。oh-my-pi 和 Pi 可以走 JuCode 网关；OpenCode 使用它自己配置的模型。Pi 本身没有审批，界面上标为“无审批”。
- 手机和网页端也能使用这些工具：可以在手机上新建 OpenCode、oh-my-pi、Pi 的对话，定时任务和需求回复也可以选择它们。
- 对话可以切到工具自己的终端界面，手机和网页端也能查看和操作。终端在电脑上持续运行，多台设备可以同时查看，断线重连后会补上最近的输出。OpenCode、oh-my-pi、Pi 也能切到各自的终端界面，并接着同一个对话继续。
- Claude Code 和 Codex 可以分别添加自定义提供商（API 地址、密钥和模型），在“设置 → 引擎后端”中管理。请求经过本机网关记录用量，密钥只保存在这台电脑上。会话固定使用开始时的提供商，模型菜单中会显示它的名称。
- 智能体可以展示交付的文件、提议定时任务（确认后才创建）、启动其他会话处理子任务。一轮结束后，回复下方会列出改动的文件、交付物、提议的任务和启动的会话。这三类工具可以在“设置 → 后台服务”中分别关闭。
- 任务完成或需要你处理时，会播放一声木块提示音。窗口正停在该对话上时不播放，可以在“设置 → 通用 → 对话”中关闭。
