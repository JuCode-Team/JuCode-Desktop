- 远程访问改为账号功能：电脑登录 JuCode 账号后，同一账号的手机和网页会自动列出这台电脑。新设备第一次连接时，电脑上会弹出“请求连接”，点允许即可；也可以继续扫二维码配对。不登录不能远程访问，局域网 / Tailscale 直连已移除。升级后之前配对的设备需要重新授权一次。
- 侧边栏改为单栏：所有项目的会话以卡片列出，可按项目筛选，下方是已归档和项目；超过 3 天没动的会话自动归档。工作区标签页和画布已移除。
- 分叉：可以从任意一轮结束处分叉，在原目录或新的 worktree 中继续；分叉的结论可以带回原会话。会话也可以直接在新的 worktree 中开始。
- 新对话改为选择一个位置：项目，或项目里的某个文件夹。
- 标题栏的项目菜单显示当前分支和未提交的行数，可以在这里打开文件夹、切换分支、提交、推送和拉取。
- 定时任务可以在独立 worktree 中运行，并设置每次运行的费用上限；运行记录列出每次运行的状态。
- 排队的消息可以“中断并立即发送”（⌘⇧Enter）。
- 用量达到限额时，输入框上方显示是哪一项限额、已用多少和重置时间，可以选择在重置后自动继续。
- 快捷键可以自定义（⌘/ 打开列表）。
- 智能体展示的图片和视频直接显示在回复中。
- 撤回用的检查点保存在 Git 引用里，重启应用后仍然可以撤回。
- 修复：后台子智能体结束后仍显示为运行中。
