- 模型菜单改为先选提供商，再选模型和思考等级。JuCode 网关的模型按厂商分组，同一系列只列最新版本，旧版本收在列表底部。Ultracode 是思考等级的最高一档，Fast 是等级旁的开关。
- 新建会话时先选项目：⌘N、标题栏、命令面板、托盘和侧栏的入口都会弹出项目列表，可用 ⌘1–⌘9 直接选择。发送第一条消息前，输入框位于页面中间。
- 正在运行的一轮显示在对话中：对话末尾显示本轮用时，运行中的工具名称有流光提示；压缩、中断、重启、切换模型等节点以分隔线显示在对话里。输入框上方只保留后台任务，点击整条即可打开任务面板。
- Claude Code 的插队（⌘↵）立即生效：当前回复和正在执行的工具会停止，插队的消息马上开始处理；前台运行的子智能体会转到后台继续运行。
- 引擎在一轮中途退出时，这一轮会结束并标明未完成，引擎恢复后可以点“继续”。
- 点击 Read 工具的一行即可打开读取的文件：图片在查看器中打开，文本跳到读取的起始行。
- 非图片文件作为附件发送，不再写进消息正文；视频不再抽帧，作为普通文件发送。
- 工作区栏用光点显示各会话的状态，悬停即可看到工作区内的会话。
- macOS 上的关闭按钮统一放在左侧。
- 远程访问有了单独的设置页。
